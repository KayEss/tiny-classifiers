# Tiny Classifiers

These are the source files for the articles found on [kirit.com](https://kirit.com/Tiny%20Classifiers/).

The main file is [tiny-classifier.cpp](./tiny-classifier.cpp), but the version on [kirit.com](https://kirit.com/Tiny%20Classifiers/tiny-classifier.cpp) is easier to read.


## Building and running

This is just a cmake project. Build however you normally do it.

There's nothing special about the build, you can also just invoke your favourite compiler however you like, but you'll need to set it to build with at least C++26. The build is only single files, so a build system is overkill in many ways.
